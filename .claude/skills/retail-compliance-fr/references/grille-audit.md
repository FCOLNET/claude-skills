# Grille d'audit conformité en magasin

Parcourir le magasin dans l'ordre du client. Chaque point : **C** conforme · **NC** non
conforme · **NV** non vérifié (avec la raison) · **SO** sans objet.
Gravité : **B** bloquant · **M** majeur · **m** mineur (définitions dans `SKILL.md`).

Un point NV n'est jamais compté comme conforme dans la synthèse.
