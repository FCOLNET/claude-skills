# Jeu de rôle — [situation]

Trios : **vendeur**, **client**, **observateur**. 6 minutes de jeu, 4 minutes de retour,
puis rotation des rôles. Imprimer chaque fiche séparément : le vendeur ne lit pas la
fiche client.

---

## Fiche CLIENT — ne pas montrer au vendeur

- **Qui vous êtes** : [profil en une ligne]
- **Ce que vous dites en entrant** : « [phrase d'ouverture] »
- **Votre vrai besoin** (à ne révéler que si on vous pose une bonne question) :
  [besoin]
- **Votre motivation dominante (SONCAS)** : [S / O / N / C / A / S]
- **Votre budget** : [montant] — vous ne le dites que si on vous le demande
- **Votre objection** (à placer après la présentation du produit) : « [objection] »
- **Ce qui vous fait acheter** : [condition]
- **Ce qui vous fait partir** : [comportement du vendeur]

## Fiche VENDEUR

- **Situation** : [rayon, moment de la journée, affluence]
- **Ce que vous savez** : [informations disponibles — produits, prix, services réels]
- **Votre objectif** : comprendre le besoin et y répondre ; une vente n'est pas
  obligatoire si le produit ne convient pas.

## Fiche OBSERVATEUR

Cocher ce que vous **voyez ou entendez**, pas ce que vous supposez.

| Étape | Comportement observable | Oui | Non | Phrase entendue |
|---|---|---|---|---|
| Accueil | Salutation et contact visuel | | | |
| Découverte | Au moins 3 questions ouvertes avant de montrer un produit | | | |
| Reformulation | Le besoin est reformulé et validé | | | |
| Argumentation | Arguments reliés au besoin exprimé (CAP) | | | |
| Objection | Reformulée avant d'y répondre | | | |
| Conclusion | Question de choix ou récapitulatif | | | |
| Complément | Un complément utile proposé, refus accepté | | | |
| Cadre légal | Aucune affirmation inexacte (garantie, retour, stock, prix) | | | |

**Retour au vendeur** (dans cet ordre) :
1. Un point fort précis : « Quand tu as dit… »
2. Un seul axe de progrès : « La prochaine fois, essaie… »
3. Son engagement : « Qu'est-ce que tu gardes pour tes prochaines ventes ? »

---

## Variante obligatoire dans chaque module

Au moins un scénario où **la bonne réponse est de ne pas vendre** : produit inadapté
au besoin, rupture, client mineur pour un produit réglementé, demande hors de l'offre
du magasin. Le vendeur réussit s'il oriente correctement le client.
