# Règles d'or du merchandising — Référentiel

## Les 5 niveaux de tablette

| Niveau | Nom | Hauteur approx. | Attractivité | Usage recommandé |
|---|---|---|---|---|
| N5 | Niveau chapeau | >180 cm | Faible | Stockage visible, grandes boîtes, signalétique |
| N4 | Niveau yeux ++ | 160-180 cm | Très forte | Best-sellers, nouveautés, produits à forte marge |
| N3 | Niveau main + | 120-160 cm | Forte | Produits A et B, MDD |
| N2 | Niveau main | 80-120 cm | Bonne | Produits B, familles secondaires |
| N1 | Niveau sol | <80 cm | Faible | Produits C, grands formats, packs, produits lourds |

## Règles des zones chaudes / froides

**Zones chaudes** (trafic naturel élevé) :
- Entrée du rayon (sens de circulation)
- Face aux allées principales
- Angles et carrefours d'allées
- Abords des caisses
→ Placer : promotions, nouveautés, produits d'impulsion

**Zones froides** (trafic faible) :
- Fond de rayon
- Extrémités peu fréquentées
- Niveaux sol et chapeau en zone froide
→ Stratégie : produits d'obligation (pain, lait) pour forcer le déplacement, ou revitaliser avec promotion

## Règle des 1/3

Pour les rayons alimentaires :
- 1/3 du linéaire = MDD (marque distributeur)
- 1/3 = marque nationale n°1
- 1/3 = autres marques et références

## Calcul du linéaire optimal

```
Linéaire optimal (cm) = (CA référence / CA catégorie) × Linéaire total catégorie
Facing minimum de lisibilité = 2 facings
Facing idéal = 3-5 facings pour produit A
```

## Types de blocking

### Blocking vertical (par marque ou famille)
```
│ Marque A │ Marque B │ MDD │ Marque C │
│ Marque A │ Marque B │ MDD │ Marque C │
│ Marque A │ Marque B │ MDD │ Marque C │
```
Usage : cosmétique, entretien, alcools, textile

### Blocking horizontal (par segment)
```
│ Premium ─────────────────────────────│
│ Standard ────────────────────────────│
│ Entrée de gamme ─────────────────────│
```
Usage : alimentaire sec, boissons, conserves

### Blocking mixte (marque × segment)
```
│ Prem-A │ Prem-B │ Prem-MDD │
│ Std-A  │ Std-B  │ Std-MDD  │
│ Eco-A  │ Eco-B  │ Eco-MDD  │
```
Usage : électroménager, high-tech, sport

## Têtes de gondole (TDG)

- Surface optimale : 120 à 200 cm de large, tous niveaux
- Renouvellement recommandé : toutes les 3-4 semaines
- Contenu type : 1 à 3 références maximum (lisibilité)
- Ratio prix TDG : -20% à -40% vs prix normal (promotion visible)
- Signalétique obligatoire : prix barré + nouveau prix + % remise

## Cross-merchandising — Exemples par univers

| Produit principal | Complémentaire suggéré | Logique |
|---|---|---|
| Barbecue | Charbon, allume-feu, sauces | Occasion d'usage |

## Réglementation merchandising (France)

- **Affichage prix** : obligatoire sur chaque produit ou sur l'étiquette de rayon (arrêté du 3 décembre 1987 modifié)
- **Prix au kg/litre** : obligatoire pour produits alimentaires préemballés
- **Réduflation** : obligation d'information depuis le 01/07/2024 si la quantité diminue sans baisse de prix
- **Alcools** : pas de mise en avant à proximité des caisses ni en tête de gondole accessible aux mineurs dans certains départements
- **Produits phytosanitaires** : zone séparée, signalétique danger obligatoire
- **DLC courtes** : produits à DLC <30 jours doivent être en avant de rayon (rotation FIFO visible)
